REST & CoAP

The Constrained Application Protocol (CoAP) is a specialized web transfer protocol for use with constrained nodes and networks. It provides a RESTful interface similar to HTTP but is optimized for machine-to-machine (M2M) applications.

  • Low header overhead
  • UDP based reliable transmission
  • Resource discovery support
  • Asynchronous message exchanges
📶

AODV Protocol

The Ad-hoc On-Demand Distance Vector (AODV) algorithm is a routing protocol for mobile ad hoc networks. While popular, it often suffers from high routing overhead and lower energy efficiency in static lighting grids.

  • Reactive route discovery
  • Sequence numbers for loop prevention
  • Higher energy consumption
  • Frequent re-clustering overhead
